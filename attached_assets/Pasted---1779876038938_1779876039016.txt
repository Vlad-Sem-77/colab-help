## Техническое задание (v2.0 — Free Models)

### «Replit ↔ Colab Bridge: Интерактивный пульт для экспериментов с бесплатными LLM через OpenRouter»

---

### 1. Общее описание

Веб-приложение на Replit (Streamlit), которое:
- Даёт визуальный интерфейс для настройки параметров нейросетевых экспериментов.
- Отправляет запросы в Google Colab, где через OpenRouter API вызываются **только бесплатные модели**.
- После выполнения показывает не только ответ, но и **полную карточку модели**: название, провайдер, контекстное окно, цену ($0.00), рейтинг и любые доступные характеристики.
- Генерирует код для вставки обратно в Jupyter-ноутбук.

---

### 2. Ключевое изменение: работа с бесплатными моделями

#### 2.1. Стратегия выбора модели

**Вариант А: Auto-router (рекомендуемый)**
- В запросе указывается `"models": ["free"]` — OpenRouter сам маршрутизирует на любую доступную бесплатную модель.
- После ответа из поля `model` в ответе извлекается точное название модели.
- По названию делается запрос к `GET /api/v1/models/{model_id}` для получения полных характеристик.

**Вариант Б: Ручной выбор из списка free**
- При старте Replit-приложение запрашивает через Colab список всех бесплатных моделей: `GET /api/v1/models?free=true`.
- Пользователь видит выпадающий список и выбирает конкретную модель.
- Характеристики выбранной модели отображаются сразу в интерфейсе.

**В ТЗ закладываем оба варианта с переключателем.**

#### 2.2. Карточка модели (что выводится после ответа)

После получения ответа от OpenRouter, в Replit отображается блок:

```
╔══════════════════════════════════════╗
║        КАРТОЧКА МОДЕЛИ              ║
╠══════════════════════════════════════╣
║ Название:     Meta: Llama 3.1 8B    ║
║ Провайдер:    Meta                  ║
║ Контекст:     128 000 токенов       ║
║ Цена:         $0.00 / млн токенов   ║
║ Статус:       🟢 Free               ║
║ Тип:          Chat                  ║
║ Модальности:  Текст                 ║
║ Топ-рейтинг:  4.7 / 5.0            ║
╚══════════════════════════════════════╝
```

#### 2.3. Метрики выполнения

После каждого запроса — отдельный блок с метриками:

| Метрика | Откуда берётся |
|---------|----------------|
| Модель | `response.model` из ответа API |
| Токенов запроса | `response.usage.prompt_tokens` |
| Токенов ответа | `response.usage.completion_tokens` |
| Всего токенов | `response.usage.total_tokens` |
| Время выполнения | Замер на стороне Colab |
| Стоимость | `0.0000` (всегда для free) |

### 3. Дополнения к функциональным требованиям

#### 3.1. Новый блок в боковой панели: «Режим выбора модели»

- **Радио-кнопки:**
  - 🔀 Автовыбор (OpenRouter сам подберёт free-модель)
  - 🎯 Ручной выбор (показать список free-моделей)

- **При выборе «Ручной»:**
  - Кнопка «Загрузить список free-моделей» → отправляет запрос в Colab, тот дёргает `GET https://openrouter.ai/api/v1/models?free=true`.
  - `st.selectbox` с названиями моделей.
  - Под выпадающим списком — `st.json` или структурированный блок с характеристиками выбранной модели (контекст, провайдер, рейтинг, описание).

- **При выборе «Автовыбор»:**
  - Отображается текст: «OpenRouter выберет любую доступную бесплатную модель. Точная модель будет известна после ответа.»

#### 3.2. Обновлённая кнопка «Отправить в Colab»

Отправляет JSON с дополнительными полями:

```json
{
  "task_type": "text_generation",
  "mode": "auto",           // "auto" или "manual"
  "model": null,            // null для auto, название модели для manual
  "params": {
    "prompt": "...",
    "temperature": 0.7,
    "max_tokens": 200
  }
}
```

#### 3.3. Обновлённый блок вывода результата

Порядок отображения после получения ответа:

1. **Карточка модели** (st.container с границей, см. макет выше).
2. **Метрики выполнения** (st.metrics в ряд: токены, время).
3. **Ответ модели** (st.code или st.markdown).
4. **Кнопка «Сгенерировать код для Colab»** — теперь в генерируемый код также включается название модели и её характеристики как комментарий.
5. **Кнопка «Скачать TXT-отчёт»** — в отчёт включается полная карточка модели.

#### 3.4. Шаблон генерируемого кода (обновлённый)

```python
# ============================================================
# Сгенерировано Replit ↔ Colab Bridge
# Дата: 2026-05-27 14:30:00
# Режим: Автовыбор free-модели
# ------------------------------------------------------------
# КАРТОЧКА МОДЕЛИ:
#   Название:    Meta: Llama 3.1 8B Instruct (free)
#   Провайдер:   Meta
#   Контекст:    128 000 токенов
#   Цена:        $0.00 / млн токенов
#   Рейтинг:     4.7 / 5.0
# ------------------------------------------------------------
# Параметры запроса:
#   Temperature: 0.7
#   Max tokens:  200
#   Промпт:      "Напиши хокку про программирование"
# ============================================================

import openai

client = openai.OpenAI(
    base_url="https://openrouter.ai/api/v1",
    api_key="ВАШ_КЛЮЧ",
)

response = client.chat.completions.create(
    model="meta-llama/llama-3.1-8b-instruct:free",  # ← автоопределено OpenRouter
    messages=[
        {"role": "user", "content": "Напиши хокку про программирование"}
    ],
    temperature=0.7,
    max_tokens=200,
)

print("Модель:", response.model)
print("Токенов запроса:", response.usage.prompt_tokens)
print("Токенов ответа:", response.usage.completion_tokens)
print("-" * 40)
print(response.choices[0].message.content)
# ============================================================
```

### 4. Дополнительный эндпоинт в Colab-бэкенде

#### 4.1. `GET /models/free`

Возвращает список бесплатных моделей с их характеристиками.

**Логика:**
1. Выполняет HTTP GET на `https://openrouter.ai/api/v1/models?free=true` (бесплатный эндпоинт, не требует ключа).
2. Фильтрует: только модели, где `"status": "free"` или цена `0`.
3. Возвращает JSON-массив с полями: `id`, `name`, `description`, `context_length`, `pricing`, `top_provider`, `ratings`.

**Формат ответа:**
```json
{
  "status": "ok",
  "models": [
    {
      "id": "meta-llama/llama-3.1-8b-instruct:free",
      "name": "Meta: Llama 3.1 8B Instruct (free)",
      "description": "Lightweight 8B model...",
      "context_length": 131072,
      "pricing": {"prompt": "0", "completion": "0"},
      "top_provider": "meta",
      "average_rating": 4.7
    },
    ...
  ],
  "count": 15
}
```

**В: Что если free-модели перегружены?**
