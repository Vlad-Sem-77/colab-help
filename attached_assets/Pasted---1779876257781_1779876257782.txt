## Вся система — это три независимые программы, которые общаются через интернет

Представьте аналогию с доставкой еды:

---

### 1. Replit → это «приложение на телефоне»

**Что это физически:**
- Это облачный сервис `replit.com`. Вы заходите на сайт, создаёте проект (Repl), и он крутится на их серверах.
- Внутри вашего Repl — маленький виртуальный компьютер с Linux, где установлен Python.

**Что там запущено:**
- Файл `main.py` — программа на Python, использующая библиотеку **Streamlit**.
- Streamlit — это фреймворк, который из Python-кода делает веб-интерфейс с кнопками, слайдерами, полями ввода. Вам не нужно писать HTML/CSS/JavaScript.
- Когда вы нажимаете Run в Replit, он запускает команду `streamlit run main.py`, и выдаёт публичную ссылку на ваш интерфейс.

**Роль в системе:**
- Показывает красивый интерфейс с кнопками и ползунками.
- Отправляет HTTP-запросы в Colab.
- Принимает ответы и показывает их.
- Генерирует код для копирования.

**Аналогия:** Это приложение доставки на вашем телефоне. Вы тыкаете в кнопки «хочу пиццу, температура 0.7», а оно отправляет заказ на кухню.

---

### 2. Google Colab → это «кухня ресторана»

**Что это физически:**
- Это облачный сервис `colab.research.google.com`, принадлежащий Google.
- Вы открываете Jupyter-ноутбук в браузере. Но в отличие от обычного Jupyter, который крутится на вашем компьютере, Colab работает на мощных серверах Google с GPU.
- Colab даёт вам **бесплатную виртуальную машину** (компьютер с Linux, Python, GPU) на время сессии.

**Что там запущено:**
- Ячейка с Python-кодом, который я написал выше.
- Этот код запускает **Flask** — микро-веб-сервер на Python. Flask слушает порт 5000 и ждёт HTTP-запросов.
- Этот же код запускает **ngrok** — программу, которая создаёт туннель из интернета в ваш Colab (потому что Colab изначально не доступен извне).
- Flask + ngrok вместе делают из Colab настоящий **бэкенд-сервер**, доступный по URL.

**Роль в системе:**
- Принимает запросы от Replit через интернет.
- Обращается к OpenRouter API с вашим ключом.
- Выполняет Python-код (включая кастомный, который вы прислали).
- Возвращает результат обратно в Replit.

**Аналогия:** Это кухня ресторана. Принимает заказы, готовит (ходит к OpenRouter за ингредиентами), отдаёт готовое блюдо.

---

### 3. OpenRouter → это «оптовый склад ингредиентов»

**Что это физически:**
- Сторонний облачный сервис `openrouter.ai`.
- Это API-шлюз (посредник), который даёт единый доступ к десяткам разных нейросетей.

**Роль в системе:**
- Принимает запрос в формате OpenAI-совместимого API.
- Выбирает подходящую бесплатную модель (Llama, Gemma, Mistral и т.д.).
- Перенаправляет запрос на сервера, где реально крутится эта модель.
- Возвращает ответ.

**Аналогия:** Это оптовый склад, куда кухня (Colab) ходит за ингредиентами. Вы говорите «дай мне бесплатные помидоры», а склад сам решает, чьи помидоры сегодня свежее — фермера Llama или фермера Gemma.

## Схема потоков данных

```
Ваш ноутбук/телефон
        │
        │  Браузер
        ▼
┌─────────────────────────────────────┐
│  REPLIT (облачный сервер)           │
│  ┌───────────────────────────────┐  │
│  │ Streamlit (веб-интерфейс)     │  │
│  │ - кнопки, слайдеры, поля      │  │
│  │ - HTTP-клиент (requests)      │  │
│  └───────────────────────────────┘  │
│  Физически: Linux-контейнер         │
│  в облаке Replit                    │
└──────────────┬──────────────────────┘
               │ HTTP POST
               │ (JSON: промпт, температура)
               ▼
┌─────────────────────────────────────┐
│  GOOGLE COLAB (облачный сервер)     │
│  ┌───────────────────────────────┐  │
│  │ Flask (веб-сервер)            │  │
│  │ - слушает порт 5000           │  │
│  │ - обрабатывает запросы        │  │
│  │ - хранит API-ключ             │  │
│  ├───────────────────────────────┤  │
│  │ Ngrok (туннель)               │  │
│  │ - даёт публичный URL          │  │
│  │ - пробрасывает трафик в Colab │  │
│  └───────────────────────────────┘  │
│  Физически: виртуалка Google        │
│  с Python, GPU, 12 ГБ ОЗУ           │
└──────────────┬──────────────────────┘
               │ HTTP (OpenAI-совместимый API)
               ▼
┌─────────────────────────────────────┐
│  OPENROUTER (облачный API-шлюз)     │
│  ┌───────────────────────────────┐  │
│  │ Маршрутизатор                 │  │
│  │ - выбирает free-модель        │  │
│  │ - отправляет запрос туда      │  │
│  └────────────┬──────────────────┘  │
│               │                     │
│  ┌────────────▼──────────────────┐  │
│  │ Реальные сервера с GPU:       │  │
│  │ - Meta (Llama)                │  │
│  │ - Google (Gemma)              │  │
│  │ - Mistral                     │  │
│  │ - ...                         │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

## Коротко: что есть что

| Компонент | Тип | Где физически | Зачем |
|-----------|-----|---------------|-------|
| **Streamlit** | Библиотека Python для веб-интерфейсов | Внутри Replit | Рисует кнопки и поля |
| **Replit** | Облачная платформа | Сервера replit.com | Хостит ваш Streamlit-интерфейс |
| **Flask** | Микро-фреймворк для веб-серверов | Внутри Colab | Принимает HTTP-запросы, выполняет код |
| **Ngrok** | Утилита для туннелей | Внутри Colab | Даёт публичный URL к Flask |
| **Google Colab** | Облачная Jupyter-среда | Сервера Google | Бесплатный хостинг для Flask + выполнение Python |
| **OpenRouter** | API-шлюз к нейросетям | Сервера openrouter.ai | Единый доступ к десяткам LLM |

---

## Почему всё так сложно? Почему не сделать всё в одном месте?

**Вариант «всё в Replit»:** Replit даёт слабые виртуалки. Тяжёлые нейросети там не запустятся. Но для веб-интерфейса его мощностей хватает.

**Вариант «всё в Colab»:** У Colab нет встроенного удобного веб-интерфейса с кнопками и слайдерами. Jupyter-ноутбук — это про ячейки с кодом, а не про красивые пульты управления. Но зато есть бесплатный GPU и мощность для работы с API.

**Вывод:** Мы взяли лучшее из двух миров — интерфейс из Replit, мощности из Colab. А OpenRouter добавили, чтобы не платить за API и иметь доступ к куче моделей.
