---
name: Notebook theme choice
description: Product decision about the visual styles offered by the Notebook UI.
---

Keep both the light, wave-accented style and the Windows 95-inspired style available; let each notebook reader choose which one they prefer.

**Why:** The user explicitly chose to offer both styles rather than settle on one.

**How to apply:** Preserve the choice when revising the Notebook UI. New notebook content should remain legible and usable in both themes.
